# Karteikarten

Offline-fähige Lern-App (PWA) mit Leitner-System für zwei Rubriken: **Chinesisch** und **Neurochirurgie**.

- 5 Leitner-Boxen (1, 2, 4, 8, 16 Tage), aktives Abrufen mit Selbstbewertung
- Chinesisch: Hanzi, Pinyin mit Tonfarben, Beispielsätze, Sprachausgabe, drei Abfragerichtungen
- Neurochirurgie: Definitionen, Lückentexte, Klassifikationstabellen zum Rekonstruieren
- Innerhalb einer Rubrik alle Stapel gemischt lernen
- Statistik mit fälligen Karten und Schwachstellen
- Import aus CSV/JSON (Formate in der App unter „Daten“)
- Fertiger Kartensatz: Chinesisch HSK 1–4 (altes System, ca. 1200 Wörter mit Beispielsätzen; Wortliste aus complete-hsk-vocabulary, MIT)
- Automatischer Sync zwischen Geräten über ein privates GitHub Gist (Token mit Recht „gist“)

Die App besteht nur aus statischen Dateien und läuft über GitHub Pages.
